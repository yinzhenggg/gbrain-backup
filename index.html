Personal backup utility

GBrain Backup

GBrain Backup is a personal utility operated by the owner of the yinzhenggg GitHub account. It uses rclone to store encrypted recovery backups and checksum receipts in the owner's Google Drive.

What it does

Scheduled scripts upload encrypted backup packages, read and download backups to verify transfers, and remove older backups according to the owner's retention policy. Google Drive access requires the owner's explicit OAuth authorization.

This website provides information about the utility. It has no sign-in form and does not accept backup files, OAuth credentials or tokens.

Personal use

The utility is for the operator's own backups. It is not a public backup service and is not affiliated with Google.
